# 🎮 Word Scramble Game&#x20;

## 📌 About the Project

Word Scramble Game is a simple, interactive Python game in which players guess the correct word from its scrambled letters. Players can use hints and get three attempts to guess each word correctly.

The game includes a scoring system and a high score feature to make playing more fun.

## ✨ Features

- 🔀 Randomly scrambled words
- 💡 Hints to help guess the words
- 🎯 Three attempts for each word
- 🏆 Score tracking
- 📈 High score tracking across games in the same session
- 🔄 Option to play again
- 🎉 Performance messages based on the final score

## 🛠️ Technologies Used

- Python
- `random` module

## 🎮 How to Play

1. Run the Python program.
2. A scrambled word will appear on the screen.
3. Choose whether you want a hint.
4. Enter your guess.
5. You have three attempts to guess each word correctly.
6. Earn one point for each correctly guessed word.
7. Complete all three rounds to see your final score.
8. Try to beat your high score!
9. Choose whether to play again.

## 📊 Scoring System

- Correct answer: 1 point
- Incorrect answer after all three attempts: 0 points
- Maximum score per game: 3 points

## ▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python word-scramble-game.py
```
